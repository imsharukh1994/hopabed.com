## 📌 About

**Hopabed** is an upcoming platform focused on helping people **Find**, **Book** & **Verify** verified stays.

The product is being designed around:

- **PGs**
- **Hostels**
- **Rooms**
- **Homes**

This repository contains the **Phase 1** *Coming Soon* website used to establish the Hopabed brand and initial online presence.

👉 **Main Repository:** [github.com/imsharukh1994/hopabed.com](https://github.com/imsharukh1994/hopabed.com)
